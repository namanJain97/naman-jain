# Delhi Drive: Open City (Android prototype)

A lightweight 3D free-roam driving prototype built with Godot 4.4.1. Procedural Delhi-inspired city blocks, drivable car and motorcycle, chase camera, day/night toggle, simple traffic props, touch controls and vehicle switching.

## Build
Open with Godot 4.4.1. Android export preset: **Android**. GitHub Actions workflow builds a debug APK and uploads it as an artifact on pushes affecting this folder.

This is an original prototype using procedural primitive geometry; it does not include licensed real-world vehicle brands or copied game assets.
